MSDS ডিলার ম্যানেজমেন্ট সফটওয়্যার — আপডেট নোট
================================================================

এই ধাপে যা করা হলো
---------------------

1) গতি — ক্যাশিং (ফ্রন্টএন্ড + ব্যাকএন্ড দুই জায়গাতেই)
   ফ্রন্টএন্ড (ব্রাউজার):
   - সব "লিস্ট/ভিউ" ধরনের কল (ড্যাশবোর্ড, প্যাকেজ, গ্রাহক, অর্ডার,
     বিক্রি, কমিশন, খরচ, ডিলার লিস্ট, এজেন্সি তথ্য, সংস্থার তথ্য)
     এখন ১০-৩০ সেকেন্ডের জন্য ব্রাউজারেই ক্যাশ হয়ে থাকে
   - একই সেশনে কোনো সেকশনে দ্বিতীয়বার গেলে (সময়ের মধ্যে) কোনো
     নেটওয়ার্ক কল ছাড়াই তাৎক্ষণিক দেখাবে
   - যেকোনো এড/এডিট/ডিলিট করার সাথে সাথে পুরো ক্যাশ খালি হয়ে যায়,
     তাই কখনো পুরনো/ভুল তথ্য দেখানোর ঝুঁকি নেই

   ব্যাকএন্ড (Apps Script):
   - ডিলার তালিকা, এজেন্সি তথ্য, সংস্থার তথ্য — এই তিনটি (যা প্রায়
     প্রতিটি পেজেই বারবার পড়া হয়) এখন সার্ভার-সাইডেও ৩০-৬০ সেকেন্ড
     ক্যাশ হয়ে থাকে, ফলে Google Sheet থেকে বারবার রিড কমে গেছে
   - সংশ্লিষ্ট তথ্য আপডেট হলেই (ডিলার এডিট, স্ট্যাটাস বদল, নমিনি
     এডিট, এজেন্সি সেটাপ, সংস্থার তথ্য এডিট, নতুন ডিলার রেজিস্ট্রেশন)
     এই ক্যাশ স্বয়ংক্রিয়ভাবে খালি হয়ে যায়

   ⚠️ সততার সাথে বলা দরকার: Google Apps Script Web App-এর প্রতিটি
   HTTP কলেই Google-এর নিজস্ব অবকাঠামোগত একটি ন্যূনতম বিলম্ব (সাধারণত
   ১-৩ সেকেন্ড) থাকে যা কোনো কোড দিয়েই সম্পূর্ণ দূর করা সম্ভব না।
   উপরের ক্যাশিং একই সেশনে বারবার একই ডাটা আনার প্রয়োজনটাই দূর করে
   দেয় (প্রথমবার ছাড়া) — এটাই এই প্ল্যাটফর্মে যতটা সম্ভব গতি বাড়ানোর
   ব্যবহারিক সীমা।

2) গ্রাহক কার্ড — হেডার/ফুটার রিডিজাইন (নতুন স্পেসিফিকেশন অনুযায়ী)
   - হেডার: বাম পাশে লোগো (এজেন্সি সেটাপে দেওয়া লোগো URL থাকলে সেটা,
     না থাকলে "MSDS"), ঠিক মাঝখানে সংস্থার নাম, নামের নিচে মোবাইল নং
     (ডান পাশে একটি অদৃশ্য স্পেসার রাখা হয়েছে যাতে মাঝেরটা সত্যিকারের
     center-এ থাকে)
   - ডিভাইডার লাইন
   - কার্ড-ইনফো: বামে তিন-কলামের একটি মিনি-টেবিল — নাম | : | মান
     (প্রতিটি সারি Label, কোলন চিহ্ন, ভ্যালু — আলাদা কলামে সারিবদ্ধ)
   - ডান পাশে QR কোড
   - ফুটার: ডিলারের নাম ও মোবাইল নং, আলাদা ব্যাকগ্রাউন্ড কালারসহ

3) ডিলার লিস্টের "এডিট" — এখন সম্পূর্ণ তথ্য লোড হয়
   - আগে শুধু কয়েকটা ফিল্ড (নাম, মোবাইল, ঠিকানা) একটা ছোট পপ-আপে
     এডিট করা যেত
   - এখন "এডিট" চাপলে সরাসরি ডিলার রেজিস্ট্রেশনের অফিসিয়াল ফরমেই
     চলে যায়, এবং সেই ডিলারের সম্পূর্ণ তথ্য লোড হয়ে যায়:
     ডিলারের সব তথ্য + ছবি প্রিভিউ, নমিনির সব তথ্য + ছবি প্রিভিউ,
     এবং লগইন ইউজারনেম/পাসওয়ার্ড (প্লেইন টেক্সট, তাই সরাসরি দেখা যায়)
   - ফরমের শিরোনাম "ডিলার এডিট — [নাম]" এ বদলে যায়, বাটন "আপডেট
     করুন" দেখাবে, এবং "বাতিল" বাটন দিয়ে এডিট মোড থেকে বেরিয়ে আসা
     যাবে
   - সব তথ্য (ডিলার + নমিনি + লগইন + নতুন ছবি দিলে সেটাও) একসাথে,
     একটিমাত্র সংরক্ষণ ক্লিকে আপডেট হয়

===================================================================
সেটআপ (আপডেট পদ্ধতি)
===================================================================
1. সাতটি .gs ফাইল MasterRegistry এর Apps Script এ পুরোপুরি
   প্রতিস্থাপন করুন
2. Deploy → Manage deployments → পেন্সিল আইকন → Version: New version
   → Deploy
3. নতুন index.html ব্যবহার করুন

কোনো নতুন শীট তৈরির দরকার নেই এই ধাপে, শুধু কোড আপডেট ও redeploy
করলেই চলবে।

নতুন API একশন
===================================================================
action: getDealerFullInfo | data:{ token, dealerId } — ডিলার +
  নমিনি + এডমিন ইউজার তথ্য একসাথে ফেরত দেয় (শুধু agencyadmin)
action: updateDealerFull | data:{ token, dealerId, dealerFields,
  nomineeFields, adminUsername, adminPassword, dealerPhotoBase64
  (ঐচ্ছিক), nomineePhotoBase64 (ঐচ্ছিক) } — সব একসাথে আপডেট করে
  (শুধু agencyadmin)

সব পুরনো নিয়ম (মোবাইল টেক্সট ফরম্যাট, প্লেইন-টেক্সট পাসওয়ার্ড, রোল-
ভিত্তিক পারমিশন) আগের মতোই বহাল আছে।
