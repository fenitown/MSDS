TCB/MSDS ডিলার ম্যানেজমেন্ট সফটওয়্যার — সর্বশেষ আপডেট নোট
================================================================

জরুরি বাগ ফিক্স
----------------
"agencyadmin দিয়ে লগইন করলে 'ডিলার তথ্য পাওয়া যায়নি' দেখাচ্ছিল" —
এই সমস্যাটি Auth.gs এর loginUser() ফাংশনে ছিল, এখন স্থায়ীভাবে ঠিক করা
হয়েছে (AGENCY_ID এর জন্য Dealers ট্যাবে খোঁজা হয় না)। নতুন Auth.gs
ফাইলটি পুরোপুরি বসিয়ে দিন — কোনো ম্যানুয়াল এডিটের দরকার নেই।

===================================================================
এই আপডেটে যা যোগ/পরিবর্তন হলো
===================================================================

1) পারফরম্যান্স (সেভ ও লোড দ্রুত করা)
   - একাধিক এন্ট্রি (প্যাকেজের পণ্য, খরচ, খরচ ভাউচার) এখন একটির পর
     একটি appendRow() না করে batchAppendRows() দিয়ে একবারে লেখা হয়
     — উল্লেখযোগ্য গতি বৃদ্ধি
   - প্যাকেজ তালিকা (Packages+PackageItems) ৩০ সেকেন্ডের জন্য
     CacheService দিয়ে ক্যাশ করা হয় — একই ডাটা বারবার শীট থেকে না
     পড়ে ক্যাশ থেকে দ্রুত ফেরত দেওয়া হয় (নতুন প্যাকেজ যোগ/এডিট/ডিলিট
     করলেই ক্যাশ স্বয়ংক্রিয়ভাবে বাতিল হয়ে যায়)
   - ফ্রন্টএন্ডে "বিক্রি" ও "অর্ডার" পেজে আগে ৩টি আলাদা নেটওয়ার্ক কল
     হতো (প্যাকেজ, গ্রাহক, বিক্রি আলাদা আলাদা) — এখন একটি কম্বাইন্ড
     action (getSalesPageData / getOrdersPageData) দিয়ে একবারে সব
     ডাটা আসে, ফলে পেজ লোড অনেক দ্রুত হয়
   - বিক্রি পেজে ফিল্টার পরিবর্তন করলে (প্যাকেজ/প্রাপ্তির স্থান) এখন
     আর নতুন সার্ভার কল হয় না — একবার লোড হওয়া ডাটা থেকেই ফিল্টার
     হয়, তাই ফিল্টারিং সাথে সাথে হয়

2) প্যাকেজ কাঠামো পরিবর্তন
   PackageItems এর কলাম এখন:
     PackageID | পণ্যের নাম ও পরিমাণ | বাজার মূল্য | কম্বো মূল্য | সাশ্রয়
   - "পণ্যের নাম ও পরিমাণ" একই ঘরে লেখা হয় (যেমন: "চিনি - ১ কেজি")
   - সাশ্রয় স্বয়ংক্রিয়ভাবে হিসাব হয় (বাজার মূল্য - কম্বো মূল্য),
     ফরমেই লাইভ দেখা যায়
   - প্যাকেজের "সর্বমোট মূল্য" এখন সব আইটেমের কম্বো মূল্যের যোগফল

3) পাসওয়ার্ড উদ্ধার
   - লগইন পেজে "পাসওয়ার্ড উদ্ধার" বাটন — ক্লিক করলে NID ও মোবাইল
     নং চাইবে, মিলে গেলে ইউজারনেম ও একটি নতুন পাসওয়ার্ড দেখাবে
   - প্রযুক্তিগত কারণে (পাসওয়ার্ড হ্যাশ করা থাকে, ডিক্রিপ্ট করা যায়
     না) আসল পুরনো পাসওয়ার্ড দেখানো সম্ভব না — তাই একটি নতুন
     পাসওয়ার্ড সেট করে দেওয়া হয়, যা সাথে সাথে ব্যবহার করা যাবে
   - এটি শুধু ডিলারের প্রথম Admin ইউজারের জন্য কাজ করে

4) ব্র্যান্ডিং: TCB → MSDS
   - হেডারের লোগো বক্সে এখন "MSDS" দেখাবে (আগে TCB ছিল)

5) প্রতিটি লিস্টে এডিট/প্রিন্ট/ডিলিট
   এখন এই সবগুলো লিস্টে তিনটি বাটনই আছে:
   ডিলার লিস্ট, প্যাকেজ (এজেন্সি), কমিশন, খরচ (এজেন্সি), গ্রাহক,
   অর্ডার, খরচ ভাউচার (ডিলার)
   - এডিট বাটনে একটি পপ-আপ ফরম খুলবে, বদলে "সংরক্ষণ করুন" চাপলেই
     আপডেট হয়ে যাবে
   - প্রিন্ট বাটনে সেই একটি রেকর্ডের তথ্য একটি নতুন উইন্ডোতে খুলে
     সরাসরি প্রিন্ট ডায়ালগ চালু হবে

6) টেবিল টেক্সট অ্যালাইনমেন্ট
   - সব টেবিলের হেডার — center
   - সব টেবিলের ডাটা — center (ডিফল্ট)
   - ব্যতিক্রম (right-align): নাম, ঠিকানা, পণ্যের নাম ও পরিমাণ,
     ডিলারের নাম, ইউজারনেম — এই কলামগুলো ডান-সংলগ্ন থাকবে

7) বিক্রি ও গ্রাহক মেনুতে প্রিন্ট
   - বিক্রি মেনুতে এখন "🖨 গ্রাহক তালিকা প্রিন্ট করুন" বাটন আছে
     (প্যাকেজ+প্রাপ্তির স্থান অনুযায়ী ফিল্টার করা তালিকা প্রিন্ট হবে)
   - গ্রাহক মেনুতে আগে থেকেই বাল্ক প্রিন্ট বাটন ছিল, বহাল আছে

8) লগইন পেজ রিডিজাইন
   - গোলাকার MSDS লোগো ব্যাজ, নরম গ্রেডিয়েন্ট ব্যাকগ্রাউন্ড, শ্যাডো
     কার্ড, Hind Siliguri ফন্ট (Google Fonts থেকে), বড় বর্ডার-রেডিয়াস

9) ইনপুট বক্সে বর্ডার-রেডিয়াস
   - সব ইনপুট/সিলেক্ট/টেক্সটএরিয়া এখন 10px বর্ডার-রেডিয়াস সহ

10) বাংলা ও ইংরেজি উভয় ভাষা
    - সব ইনপুট ফিল্ড সাধারণ টেক্সট ফিল্ড, তাই বাংলা বা ইংরেজি —
      দুই ভাষাতেই লেখা যাবে, কোনো ভাষা-সীমাবদ্ধতা নেই

===================================================================
সেটআপ (নতুন করে করার দরকার নেই, শুধু ফাইল আপডেট করুন)
===================================================================
1. MasterRegistry এর Apps Script এ প্রতিটি ফাইল (Code.gs, Auth.gs,
   Crud.gs, Reports.gs, Management.gs, Commission.gs, Expense.gs)
   পুরোপুরি মুছে নতুন কোড দিয়ে প্রতিস্থাপন করুন (কপি-পেস্ট পুরো ফাইল)
2. Deploy → Manage deployments → পেন্সিল আইকন → Version: New version
   → Deploy (এতে পুরনো URL-ই বহাল থাকবে)
3. index.html নতুন করে ডাউনলোড/ব্যবহার করুন (API_URL আগে থেকেই
   বসানো আছে)
4. প্যাকেজ কাঠামো বদলে যাওয়ায় আগে থেকে তৈরি করা প্যাকেজ থাকলে সেগুলোর
   পুরনো "পণ্যের নাম/পরিমাণ/মূল্য" কলামের ডাটা নতুন কলামের সাথে মিলবে
   না — নতুন করে প্যাকেজ এন্ট্রি দেওয়াই সহজ হবে

===================================================================
নতুন/পরিবর্তিত API একশন
===================================================================
action: recoverPassword | data:{ nid, mobile } (টোকেন লাগে না)
  → { success, username, newPassword, message }

action: getSalesPageData | data:{ token }
  → { packages, customers, sales } — একবারেই সব

action: getOrdersPageData | data:{ token }
  → { packages, orders } — একবারেই সব

action: addPackage — items এখন: { naamPoriman, bazarMulyo, comboMulyo }
  (আগে ছিল: { নাম, পরিমাণ, মূল্য })

গুরুত্বপূর্ণ: মোবাইল নং টেক্সট ফরম্যাট, ফরমের বাইরে অতিরিক্ত কলাম না
হওয়া, ১২ ঘণ্টা সেশন — এসব নিয়ম আগের মতোই বহাল আছে।
