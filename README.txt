MSDS ডিলার ম্যানেজমেন্ট সফটওয়্যার — আপডেট নোট (বড় আপডেট: স্টক মডিউল)
=========================================================================

.gs ফাইল নিয়ে প্রশ্নের উত্তর
-------------------------------
না, একাধিক .gs ফাইল থাকা সফটওয়্যার স্লো হওয়ার কারণ না। Google Apps
Script পুরো প্রজেক্টটাকে (যতগুলোই ফাইল থাকুক) একসাথে লোড করে —
ফাইল কয়টা সেটা রানটাইম পারফরম্যান্সে কোনো প্রভাব ফেলে না, এটা
শুধু কোড organize রাখার সুবিধার জন্য। তাই ফাইলগুলো একসাথে না করে
আলাদাই রাখা হয়েছে (নতুন Stock.gs যোগ হয়েছে) — এতে কাজ করা ও পরে
খুঁজে বের করা সহজ হবে। আসল ধীরগতির কারণ আগেও ব্যাখ্যা করা হয়েছে:
Google এর নিজস্ব Web App এক্সিকিউশন ওভারহেড (প্রতি কলে ~১-৩ সেকেন্ড),
যেটা কোনো কোড দিয়েই সম্পূর্ণ দূর করা সম্ভব না — শুধু ক্যাশিং দিয়ে
এর প্রভাব কমানো গেছে।

===================================================================
নতুন ফাইল
===================================================================
Stock.gs — এই ফাইলটিও বাকিগুলোর মতো MasterRegistry এর Apps Script এ
যোগ করুন (+ বাটন → Script → নাম "Stock" → কোড পেস্ট করুন)

===================================================================
নতুন মেনু ও ফিচার (এজেন্সি সাইট)
===================================================================

1) স্টক (নতুন মেনু)
   সাবমেনু ক: পণ্য তালিকা
   - ফরম: পণ্যের নাম, ব্র্যান্ড, মূল্য
   - লিস্ট: সার্চ বক্স (নাম/ব্র্যান্ড দিয়ে), প্রিন্ট বাটন, প্রতি
     রোতে এডিট/ডিলিট বাটন

   সাবমেনু খ: স্টক ইন ভাউচার
   - ফরম: একই ভাউচারে একাধিক পণ্য যোগ করা যায় (পণ্য সিলেক্ট করলে
     মূল্য অটো বসে যায়, চাইলে বদলানো যায়) + সংখ্যা
   - লিস্ট: সার্চ বক্স, প্রিন্ট (অফিসিয়াল ভাউচার ফরম্যাটে — লেটারহেড,
     পণ্য তালিকা, সর্বমোট), প্রতি রোতে এডিট/প্রিন্ট/ডিলিট (ডিলিট করলে
     পুরো ভাউচারের সব পণ্য-লাইন একসাথে মুছে যাবে)

2) বিক্রয় ইনভয়েস (নতুন মেনু) — এজেন্সি থেকে ডিলারকে প্যাকেজ বিক্রি
   - ফরম: তারিখ, ডিলার সিলেক্ট করলে মোবাইল ও ঠিকানা অটো বসে যায়
   - একই ইনভয়েসে একাধিক প্যাকেজ যোগ করা যায় (প্যাকেজ সিলেক্ট করলে
     একক মূল্য অটো বসে)
   - নিচে: ডিসকাউন্ট ও পরিশোধ ইনপুট দিলে সাবটোটাল/বকেয়া লাইভ দেখা
     যায় (বকেয়া = সাবটোটাল − ডিসকাউন্ট − পরিশোধ)
   - লিস্ট: সার্চ বক্স (ডিলার/ইনভয়েস নং), প্রিন্ট, প্রতি রোতে
     এডিট/প্রিন্ট/ডিলিট

3) রিপোর্ট (নতুন মেনু, এজেন্সি সাইট) — বিক্রয় ইনভয়েসের ভিত্তিতে
   - দৈনিক/মাসিক/মোট — তিনটি ট্যাব
   - ডিলার ড্রপডাউন: নির্দিষ্ট একজন ডিলার অথবা "সব ডিলার (মোট)"
   - দেখাবে: মোট ইনভয়েস, মোট বিক্রি, মোট ডিসকাউন্ট, মোট পরিশোধ, মোট
     বকেয়া — এবং ডিলার-ভিত্তিক ব্রেকডাউন টেবিল

4) "কোনো ডাটা নেই" ও সার্চ বক্স সামঞ্জস্য
   - সব নতুন লিস্টে এবং আগের কমিশন/খরচ লিস্টেও এখন সার্চ বক্স যোগ
     হয়েছে
   - খালি লিস্টে "এখনো কোনো ডাটা নেই" জাতীয় বার্তা দেখাবে

===================================================================
সেটআপ (আপডেট পদ্ধতি)
===================================================================
1. আটটি .gs ফাইল (নতুন Stock.gs সহ) MasterRegistry এর Apps Script এ
   বসান
2. ফাংশন ড্রপডাউন থেকে "setupMasterSheet" আবার একবার Run করুন —
   Products, StockInVoucher, SalesInvoice — এই তিনটি নতুন শীট তৈরি
   হবে
3. Deploy → Manage deployments → পেন্সিল আইকন → Version: New version
   → Deploy
4. নতুন index.html ব্যবহার করুন
