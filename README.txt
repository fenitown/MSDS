MSDS ডিলার ম্যানেজমেন্ট সফটওয়্যার — আপডেট নোট
================================================================

QR কোড স্ক্যানে "Sorry, unable to open the file" — গুরুত্বপূর্ণ ব্যাখ্যা
---------------------------------------------------------------------------
এই এররটা আসলে আমাদের কোড থেকে আসে না — এটা Google-এর নিজস্ব জেনেরিক
এরর যখন কোনো script.google.com/.../exec লিংক অ্যাক্সেস করা হয় কিন্তু
সেই ডিপ্লয়মেন্টটা বৈধ/বর্তমান না। আমি Code.gs সহ সাতটা ফাইলেই
প্রকৃত সিনট্যাক্স চেক চালিয়ে নিশ্চিত করেছি — কোডে কোনো এরর নেই।

তার মানে এই সমস্যাটা কোডের না, ডিপ্লয়মেন্ট URL মিলছে না এমন কিছু।
যাচাই করুন এভাবে:

1. আপনার MasterRegistry এর Apps Script এ যান → Deploy →
   Manage deployments → বর্তমান active deployment এর "Web app" URL
   টা কপি করুন
2. index.html ফাইলে খুঁজুন (Ctrl+F): const API_URL = "..."
   — এই ভ্যালুটা ধাপ ১ এ কপি করা URL এর সাথে হুবহু (অক্ষরে অক্ষরে)
   মিলছে কিনা দেখুন
3. মিলিয়ে দেখতে: শুধু API_URL টা ব্রাউজারের নতুন ট্যাবে সরাসরি পেস্ট
   করে খুলুন (কোনো ?view=... ছাড়া) — যদি সেখানেও একই এরর আসে, তাহলে
   এটা নিশ্চিতভাবে ভুল/পুরনো URL, কোডের সমস্যা না
   যদি ওখানে ঠিকঠাক {"status":"TCB Dealer System API চালু আছে"...}
   দেখায়, কিন্তু ?view=customer&... যোগ করলে এরর আসে — তাহলে জানাবেন,
   সেটা আলাদাভাবে ডিবাগ করা লাগবে
4. যদি মিলিয়ে দেখার পরও URL ভুল থাকে, index.html-এর API_URL সংশোধন
   করুন এবং QR কোড আবার নতুন করে প্রিন্ট করুন (পুরনো প্রিন্ট করা
   কার্ডের QR পুরনো URL এনকোড করা থাকবে, সেগুলো কাজ করবে না)

===================================================================
এই ধাপে যা করা হলো
===================================================================

1) প্যাকেজ প্রিন্ট — সংখ্যাসূচক কলাম center-align
   বাজার মূল্য, কম্বো মূল্য, সাশ্রয় — এই তিনটি কলামের ডাটা এখন
   center এ থাকবে (আগে left ছিল)

2) অর্ডারে কমিশন যোগ
   Orders টেবিলে এখন নতুন কলাম: কমিশন %, মোট কমিশন, সর্বমোট মূল্য
   (= মোট মূল্য − মোট কমিশন)
   - অর্ডার ফরমে প্রতিটি প্যাকেজ-সারিতে এখন কমিশন % ইনপুট আছে
   - অর্ডার লিস্ট টেবিলে সব কলাম দেখাবে: ইনভয়েস নং, তারিখ, প্যাকেজ,
     সংখ্যা, একক মূল্য, মোট মূল্য, কমিশন %, মোট কমিশন, সর্বমোট মূল্য
   - ইনভয়েস প্রিন্টেও (এক ইনভয়েস বা সব একসাথে) এই কলামগুলো ও তাদের
     সর্বমোট যোগ হয়েছে
   - এডিট করার সময়ও কমিশন % বদলানো যাবে, বাকি সব স্বয়ংক্রিয়ভাবে
     পুনঃগণনা হবে

3) লগইন পেজ ছোট করা হয়েছে
   প্যাডিং, লোগো সাইজ, হেডিং সাইজ, লাইনের মধ্যে ফাঁকা জায়গা — সবকিছু
   কমিয়ে পেজটা উল্লেখযোগ্যভাবে ছোট করা হয়েছে, বিশেষ করে ছোট
   মোবাইল স্ক্রিনে এখন ভালোভাবে ফিট করবে

===================================================================
সেটআপ (আপডেট পদ্ধতি)
===================================================================
1. সাতটি .gs ফাইল MasterRegistry এর Apps Script এ পুরোপুরি
   প্রতিস্থাপন করুন
2. ফাংশন ড্রপডাউন থেকে "setupMasterSheet" আবার একবার Run করুন —
   Orders শীটে কমিশন %, মোট কমিশন, সর্বমোট মূল্য — এই তিনটি নতুন
   কলাম যোগ হবে (আগের ডাটা মুছে যাবে না)
3. Deploy → Manage deployments → পেন্সিল আইকন → Version: New version
   → Deploy
4. **উপরের QR সমস্যার ধাপগুলো অনুসরণ করে API_URL যাচাই করুন**
5. নতুন index.html ব্যবহার করুন

===================================================================
নতুন/পরিবর্তিত API একশন
===================================================================
action: addOrder | data:{ token, items:[{packageId,quantity,
  unitPrice,commissionPercent},...] }
  → রেসপন্সে এখন total, totalCommission, netTotal থাকে

সব পুরনো নিয়ম (মোবাইল টেক্সট ফরম্যাট, প্লেইন-টেক্সট পাসওয়ার্ড, ছবি
data-URI হিসেবে সংরক্ষণ, রোল-ভিত্তিক পারমিশন, ক্যাশিং) আগের মতোই
বহাল আছে।
